# Validation 全局态势精确时距审计

日期：2026-09-27。目的不是训练模型，而是确认当前 `relative_margin_v2` 全局态势标签在不同精确未来时距下变化有多快，从而为评估时距和展示粒度提供数据依据。

## 数据和口径

- 仅使用 `out_m2/temporal_forecast_canonical_side/validation.npz` 中的 122 场验证比赛和 34,114 个比赛方视角采样点；脚本未打开 train/test 压缩档。SQLite 只查询这些验证集 game ID。
- 原始比赛状态是 1 秒分辨率，验证输入点每 3 秒采样。目标只从 `issued_at + horizon` 的整数秒精确读取，不使用插值、最近邻或向前填补。
- 持久性预测使用当前验证样本的 `base_mode`。未来真值按 `forecast.temporal._mode_from_groups` 的 `relative_margin_v2` 规则从精确目标秒的原始实体状态重算。
- 表内主结果先按每场比赛、红蓝视角分别算分，再在每场内对红蓝等权平均，最后各场等权平均。准确率区间采用按比赛成组的配对 bootstrap。覆盖率分母是验证输入点总数；比赛结束后的目标秒不算可评分。

| 15 秒 | 66.55% | 45.33% | 33.45% | 96.42% | 32,894 |

| 30 秒 | 60.41% | 38.06% | 39.59% | 92.85% | 31,674 |

相邻时距间的持久性准确率下降全部达到配对区间不跨零：5→10 秒 −6.07pp（95% CI −6.84 至 −5.35）；10→15 −3.69pp（−4.27 至 −3.10）；15→20 −2.87pp（−3.45 至 −2.28）；20→30 −3.26pp（−3.97 至 −2.58）；30→45 −3.00pp（−3.97 至 −2.03）；45→60 −1.97pp（−2.92 至 −1.00）；60→90 −2.86pp（−4.28 至 −1.41）；90→120 −2.23pp（−3.38 至 −1.08）。

## 对时距和展示粒度的判断

在这个全局标签上，状态变化是持续、显著的渐进过程，没有某个单独秒数之后准确率突然断崖式发散。10 秒附近下降最快；15–30 秒仍每档约下降 2.9–3.7 个百分点；45 秒以后下降幅度变缓，但 120 秒时持久性准确率已接近 50%，Macro-F1 只有 28.65%，且可评分样本覆盖降至 71.39%。因此：

- 10/30/60/120 秒可继续作为标准对比点，便于和现有模型报告衔接；不能把它们解释为数据自然产生的四个转折点。
- 若用于可视化展示粒度，验证集支持 **≤10 秒细节、15–30 秒中等概括、45–60 秒粗粒度、90–120 秒趋势/风险摘要**。90–120 秒仍有评分样本，但不支持精细状态断言。
- 这组数字是持久性基线的目标标签变化率，不是模型的逐字段误差，也不证明位置、血量等字段在相同秒数发散。实体功能区和连续位置需要独立地按精确未来秒复算，不能直接套用全局态势的粒度结论。
