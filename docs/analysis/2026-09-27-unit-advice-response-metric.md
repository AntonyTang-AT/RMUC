# 单位建议：行为响应指标与展示规则

日期：2026-09-27。复现命令：`python eval/audit_unit_recommendations.py`。审计使用赛程最早 8 场完整对局、红蓝双方、精确 `t+3` 和 `t+10` 位置；相邻帧不作为独立样本，区间按整场对局聚类抽样。

## 评分分层

| 层 | 当前指标 | 能回答的问题 | 不能据此声称 |
|---|---|---|---|
| 可执行性 | 首步是否属于当前区域或区域图合法邻区 | 建议路线第一步在地图规则上是否合法 | 单位能否在限定时间到达、路线是否安全 |
| 行为响应 | `t+3/t+10` 实际区域是否等于建议区；与保持原区基线对照。对移动建议另算有符号方向进度 | 后续可见运动是否与建议方向一致 | 指令已经下发或单位遵从建议 |
| 结果代理 | 后续可观测的 HP、设施血量、资源阶段及区域控制变化 | 建议发出后场上发生了什么 | 这些变化是建议造成的 |
| 因果效果 | 当前不可识别 | — | 无实际控制指令/确认日志，也没有反事实实验，不能声称策略收益 |

方向进度代理定义为 `clip((d_issue - d_future) / d_issue, -1, 1)`，其中 `d` 是机器人当前位置到建议首步区域中心的地图距离。大于 0 表示观测上更接近目标，等于 0 表示距离没变，小于 0 表示更远。原地不动基线为 0。该代理比“3 秒内已经跨进目标区”更适合短窗内还没越过区域边界的移动，但它仍是几何代理：不衡量障碍、朝向、可行驶路线长度或机器人是否收到指令。

方向进度按整场对局等权的均值 95% 区间：红方 `t+3` +0.000（−0.069, +0.062），蓝方 +0.076（+0.034, +0.125）；红方 `t+10` −0.178（−0.313, −0.062），蓝方 −0.056（−0.135, +0.012）。方向进度的大于零比例和区域命中率不应替代置信区间或基线。

**当前结论：**区域图首步合法性很高，但仅能证明路线图约束满足。非原地建议样本主要是低血量撤退：3 秒内机器人常还在原区域；到 10 秒时，目标命中仍远低于原地基线，朝目标的几何变化也没有稳定改善。因此，现有记录不支持说移动建议已经有效或执行成功。应先改进撤退目标和时间/速度可达性估计，并接入实际控制器的指令与 ACK 日志，再评价“建议是否被执行”。

## 单位建议展示

折叠视图只保留动作、目标/首步区域和触发条件，例如：`现在：先撤向红侧掩护区；触发：血量低于30%。` 理由放在结构化详情中，停止条件也保留在那里；没有可靠目标或路线时显示“暂不建议具体移动或攻击”，不编造一个目的区。建议仍是基于当下可见状态的条件提示，不是对实际下发动作的预测。

## 当前不能评分的字段

- **是否执行/遵从：**数据没有控制器下发指令、机器人 ACK 或动作命令时间戳。之后位置朝某区移动只记作“行为响应代理”。
- **攻击命中与目标损伤：**没有可确认的弹药—目标实体对应关系；附近最近敌人不能作为实际攻击对象。
- **资源采集/兑换完成：**历史逐机器人资源持有、采集和兑换字段不足，不能只凭工程车位置推定完成。
- **建议对胜负、设施结果的因果贡献：**其他机器人动作与对手反应同时影响结果；当前离线回放不是干预实验。
- **真实路线时长：**区域图能检查相邻关系，但逐机器人速度上限、转向时间和障碍绕行成本尚未进入这份指标，合法路线不等于 3 秒或 10 秒可达。
