# 固定后的时序预测训练合同

本轮重训固定为 `rm-temporal-contract-v1`，在重新评估前不改变以下三项约定。

## 1. 标签和时间

- 原始状态分辨率：1 秒。
- 模型发出预测的步长：3 秒。
- 评估时距：10、30、60、120 秒，目标严格取 `issued_at + horizon` 的整秒状态。
- 全局标签：`relative_margin_v2`。
- 输入只使用 `observed_at <= issued_at` 且 `received_at <= issued_at` 的观测。
- 红蓝双方按同一场比赛分组，不能跨比赛拆分窗口。

## 2. 缺失、阵亡和不可观测字段

- `-1` 表示 unknown 或 censored，不参与该字段损失和评分。
- presence=0 只表示目标时刻明确不存在/已阵亡；缺失观测不能当作阵亡。
- 阵亡只接受明确 `life_state=destroyed` 或 `hp<=0` 证据。
- 敌方协议不可见字段保持 unknown，不做未来填补。
- 攻击目标、采矿、携矿等没有稳定真值的字段只作为规则解释层，不计入模型综合分。

## 3. 综合评分字段

正式评分只包含有监督真值的字段：全局态势、敌方趋势、敌方区域、单兵存活、功能区、位置、血量和路线合法性。

每个字段先与对应的持久性、匀速外推或合法区域转移基线比较，再转换成相对技能分数；统计顺序固定为“场内红蓝等权，再比赛等权”，置信区间以整场比赛为 Bootstrap 单位。

本轮模型使用 `evidence_adaptive_v1` 损失：10 秒强调存活和位置，30 秒强调敌方趋势和区域迁移，60 秒保留概率趋势，120 秒只保留低权重宏观摘要。
