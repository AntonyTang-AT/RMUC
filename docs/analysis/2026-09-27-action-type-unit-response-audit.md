# 单兵建议按动作与兵种分层的响应代理审计

## 范围与口径

- 数据：`out_m2/advice_action_type_response.json`，脚本为 `eval/audit_advice_action_type_response.py`。
- 样本：8 场比赛（ID 见 JSON），红蓝双方；每 3 秒一个建议锚点。分别检查精确的 +3 秒和 +10 秒回放记录。
- 分层：动作 × 兵种 × 视角方。共 5,554 条建议：`cover_and_confirm_target` 4,121 条、`continue_attack_visible_target` 895 条、`retreat_low_hp` 538 条。以下重点看掩护确认与低血撤离；攻击建议不重复英雄开火事件专项审计。
- 置信区间：脚本对整场比赛做 4,000 次 cluster bootstrap，避免把同一场比赛里的锚点误当作独立样本。少于 5 场比赛的分层仅作提示，不作稳定结论。
- 这里的“响应”仅指未来观测到的区域保持、距离变化、路线区域进度或开火事件。这些都不是指令执行记录、建议准确率或建议带来的因果收益。

## 可计分情况与主要发现

所有 5,554 条建议的首步都通过现行功能区通行图检查（合法率 100%）。这只是静态路径可行性门槛，区分不了建议质量。

`cover_and_confirm_target` 是当前最常见的建议，占 74.2%（4,121/5,554）；语义是留在当前区观察、确认目标，不单独追击。其 +10 秒区域保持率为 58.2%（2,346/4,033）；红方 62.6%（1,307/2,089），蓝方 53.4%（1,039/1,944）。该动作没有明确的任务完成事件可供验证，区域保持只算“行为响应代理”，不能用它证明建议有效。大量建议共用同一动作模板，确实显得笼统；缺少威胁类型、掩护目标、防守目标和重新评估条件等可观察理由字段。

`retreat_low_hp` 暴露了更明显的“文字承诺强于现有证据”问题。该动作的 10 秒结果中，525/538（97.6%）有可用位置，但仅 22/525（4.2%）到达建议的首个目标功能区；312/538（58.0%）能按脚本口径判定是否沿建议路线前进，其中 22/312（7.1%）区域序号前进。与此同时，目标区几何距离在 277/525（52.8%）样本中缩短。可见“目标区尚未到达”不能等同于“没有向撤离方向移动”；当前路线区域离散指标可能太苛刻，几何距离指标也只能说明靠近区域中心，不能证实机器人执行了建议。

分层例子：蓝方步兵4有 135 条撤离建议、8 场比赛参与；10 秒距离缩短 68/132（51.5%，比赛 cluster bootstrap 95% CI [36.4%, 58.2%]），但到达首步区域仅 4/132（3.0%，CI [0%, 5.2%]），路线区域进度 4/90（4.4%，7 场比赛，CI [0%, 6.3%]）。红方步兵4有 94 条，路线进度为 0/59，但只覆盖 1 场比赛，不能据此判定该兵种的普遍问题。红方步兵3路线进度为 5/9（55.6%），也只覆盖 2 场比赛，区间很宽 [0%, 71.4%]。这些结果支持“目前的分区到达/路线指标与短时位移不一致，需要改进评估定义”，不支持“撤离建议导致或未导致安全收益”。

## 建议的最小改动

不据此改变撤离策略或阈值。建议在产品与指标命名上把当前的 `progress_toward_safe_zone` 拆成可解释字段：

1. `first_step_zone_arrival_10s`：是否进入指定首步区域；当前结果很低，应只作为严格到达指标。
2. `distance_reduction_to_first_step_zone_10s`：到首步区域多边形边界的距离变化，而不是到区域中心的距离；统计其连续值和改善比例。边界距离可避免机器人已经进入区域附近、但未到质心时被误判为无进展。
3. `legal_route_zone_progress_10s`：独立保留，并明确标为路径一致性代理；路线中间点是否真实经过目前没有连续轨迹日志，不能等同执行情况。

建议文字可以继续具体说明“首步目标区”和低血触发原因，但应避免暗示短窗口内必然到达或已经降低暴露。若要验证安全收益，需要动作/指令日志及撤离前后遭受伤害、生存状态的对照设计；现有回放只能给出观察关联。

## 限制

1. 只有 8 场且不是按比赛阶段均衡抽样；部分兵种×阵营分层少于 5 场，CI 不稳定。
2. 没有真实下达指令、采纳/拒绝、路径控制器状态或决策者日志；未来位置不等于实际执行建议。
3. 时间戳能匹配到 +3/+10 秒位置，不代表中间连续轨迹可见；“区域路线进度”低可能来自采样过疏、路线区域定义或实际路线不同。
4. HP 变化、生存、开火是混杂因素下的观察结果，未控制对手、场景、碰撞和其他队友行为，不可解释成建议效果。
