# 分层专家模型与安全评估结果

本轮使用 `hierarchical_expert_v1`：单机器人编码器、阵营/兵种编组、59 区域邻接图消息传递、全局专家/实体专家、时距专用头、速度约束位置解码、阵亡风险和位置不确定性头。

评估采用流式内存映射脚本，不把逐帧账本保存在内存。完整测试集 35,768 行，batch=128，GPU 推理完成；缓存位于 D 盘，不占用项目所在 F 盘。

| 时距 | 全局态势模型/持久性 | 敌方趋势模型/稳定基线 | 敌方区域模型/持久性 | 单兵位置 MAE 模型/基线 | 单兵存活模型/基线 | 功能区准确率 | 血量 MAE 模型/基线 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 10s | 62.2% / 70.5% | 48.5% / 47.4% | 59.1% / 68.7% | 0.060 / 0.057 | 88.1% / 72.9% | 45.9% | 0.149 / 0.438 |
| 30s | 56.4% / 59.2% | 49.4% / 30.7% | 52.6% / 56.1% | 0.101 / 0.095 | 87.6% / 72.9% | 45.0% | 0.159 / 0.463 |
| 60s | 54.3% / 54.2% | 53.7% / 25.5% | 48.9% / 51.0% | 0.130 / 0.114 | 86.6% / 72.9% | 43.5% | 0.164 / 0.479 |

结论：分层结构明显改善了敌方趋势、存活和血量预测；全局态势在 60/120 秒略高于持久性，10/30 秒仍低于持久性；位置和区域预测仍需要进一步的速度/区域转移专用训练。当前模型可作为候选，不直接替换默认模型。
