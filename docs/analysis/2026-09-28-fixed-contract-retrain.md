# 固定合同重训结果

本轮使用 `rm-temporal-contract-v1`，输入为 329 维因果运动特征，模型为 3 层 TCN+Transformer，hidden=192、4 heads、40 帧上下文，在 GPU 上训练。使用 `evidence_adaptive_v1` 损失，验证集早停，最佳验证损失为 0.579789（第 2 个 epoch）。

结论：本轮模型在敌方趋势、存活和血量估计上有实际增益，但全局态势、区域和短时坐标仍不如简单基线，因此没有替换生产默认。下一轮应拆分全局/实体专家，并使用速度约束的位置增量解码；不能继续单纯加深共享骨干。
