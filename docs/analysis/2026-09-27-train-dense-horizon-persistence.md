## 分段变化与结论

| 区间 | 持久性Acc变化（95%比赛CI） | 切换率变化（95%比赛CI） |
|---:|---:|---:|
| 3→15s | -18.06pp [-18.84, -17.31] | +18.06pp [+17.29, +18.85] |
| 15→30s | -7.10pp [-7.71, -6.46] | +7.10pp [+6.51, +7.73] |
| 30→60s | -4.05pp [-4.90, -3.19] | +4.05pp [+3.20, +4.88] |
| 60→90s | -3.18pp [-4.02, -2.36] | +3.18pp [+2.35, +3.98] |
| 90→120s | -1.97pp [-2.82, -1.10] | +1.97pp [+1.11, +2.77] |

- 最大的相邻 3 秒持久性准确率下降出现在 3→6 秒，变化 -7.51 个百分点（比赛 bootstrap 95% CI -7.87 至 -7.15）。
- 最大的相邻 3 秒切换率上升出现在 3→6 秒，变化 +7.51 个百分点（95% CI +7.14 至 +7.87）。
- 持久性准确率与切换率在相同样本上互为补数。逐 3 秒扫描能定位四个稀疏刻度之间变化较快的区间，并显示对局提前结束造成的覆盖下降；但它只诊断标签本身随时间的可预测性，不代表已训练预测器在该时距的准确率，也不能单独作为模型硬舍弃点。
- 相比现有 10/30/60/120 秒审计，本次新增了中间时距的精确标签切换、持久性准确率、Macro-F1、类别平衡准确率和覆盖趋势，以及相邻 3 秒变化的比赛级配对区间。若要得出“模型在某时距开始失效”，仍需在相同密集标签上训练/评估整局分组 OOF；本次按约束不做该训练。
