# 预测字段 × 时距的保留与权重阈值

日期：2026-09-27。目的：把现有数据可支持的“字段、时距、用途”拆开评估。下表是验证阶段的临时证据等级，不是生产默认或最终验收等级；当前 validation 已被多轮开发使用，最终权重还需冻结协议后的新比赛确认。

## 判定合同

不要用标签自相关或 Pearson 相关系数单独判断预测有用。主要比较必须是**同一时距、同一数据合同、同一覆盖样本上的模型与简单基线之配对差**，并以整场为重采样单位、场内红蓝等权。

- **分类类别**：报告 Accuracy、固定类别 Macro-F1、Balanced Accuracy、逐类召回；概率输出另报告 Brier、LogLoss 与覆盖率。主模型增量的区间必须和点估计使用同一比赛等权汇总。
- **连续位置/状态量**：与当前位置持久性和简单物理外推比较米制 MAE/RMSE、区域命中和覆盖率。预测目标是编组质心时，结论不能外推到单个机器人。
- **保留**：比赛级配对差稳定优于基线，覆盖足够，且类别均衡质量/关键类别没有超出预定容忍范围的退化。
- **降级为概率参考**：点估计有增益但区间跨零，或总体 Accuracy 增益伴随 Macro-F1/BA/少数类召回退化。显示概率与适用时距，不做单类硬结论。
- **隐藏/剔除主评分**：在独立整场重复评估中，增量区间上界仍不超过零或低于预先声明的最小实用效应，且没有其他明确决策价值；低覆盖或标签合同不一致也不得加权。
- **权重**：只在冻结评估合同后计算。对每个任务×时距用其适当损失相对基线的 Skill Score；可采用 `raw_weight = coverage × max(0, LCB(skill) − δ)`，再在同一任务内归一。`δ` 是上线前依据决策代价定下的最小实用增益。若 Macro-F1/关键召回超过容忍度地变差，对硬分类权重置低或归零；概率展示可保留其自己的 Brier/LogLoss 权重。跨任务的总权重还需要业务损失换算，不能直接混合 Accuracy、米和 Brier。

若置信区间很宽且同时包含有用增益和退化，结论是“证据不足、先低权重”，不是“已证明无效”。若多个候选在同一 validation 上反复比较，报告只能标开发证据；最终测试不能再被用于挑阈值。

## 如何据此调整系统

1. 现在不要依据单一 Pearson 相关系数给所有字段分权。已存在的证据支持字段级差异：短时编组质心的因果速度增量明确；敌方 30 秒趋势从可见运动摘要得到可重复增益；全局态势总 Accuracy 的增量比 Macro-F1 可靠；单体区域模型的相对技能尚未从持久性曲线中证明；局内在线调权目前应关闭。
2. 先将上述等级作为实验展示策略，而非正式业务权重。短时位置可以突出，远时距区域/单体坐标要降为概率方向；全局态势概率保留，类别硬判断单独降权。
3. 下一轮冻结 `field × horizon × coverage` 指标和最小实用效应 `δ`，只用外层训练数据/内层比赛折选权重；最终留出比赛只评分一次。
4. 专家路由、局内校准的收益也必须按同一 field×horizon 合同，先与固定通用模型和简单基线成对比较。若校准只修正 Brier 而不提升硬分类，不把它描述为 Accuracy 提高。
