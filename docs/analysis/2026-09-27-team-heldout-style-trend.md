# 敌方风格分型：严格未见队伍评估

日期：2026-09-27。只读取训练分区；validation/test 不用于拟合或方案选择。本实验以原始比赛元数据构造身份隔离折，但队伍/学校名称不进入任何预测特征。

## 身份数据审计

压缩 NPZ 的确不含队伍身份，`data/rm.db` 也是 0 字节；但原始只读库 `数据与资料/rmuc_2026_region_dataset.sqlite` 的 `matches` 表含官方红方学校、蓝方学校、game id。逐场将该表和紧凑训练集按 `game_id` 映射：

| 分区 | 比赛数 | 可映射比赛 | 不同学校队伍 | 与训练队伍重合 |
|---|---:|---:|---:|---:|
| train | 363 | 363 | 64 | — |
| validation | 122 | 122 | 48 | 16 |
| test | 128 | 128 | 32 | 0 |

之前“无法做 held-out-team 评估”的结论只适用于压缩 NPZ 缺少身份字段的观察；它忽略了原始 SQLite 元数据。下述切分将队伍名只用作 grouping/scoring 信息，模型特征中没有队伍 ID、学校名或未来数据。

## 五折外层队伍留出

主要任务为 30 秒敌方趋势（推进/稳定/撤退）。每折随机但固定地留出约 12–13 支学校队伍作为**对手**；凡涉及该折留出队伍的整场比赛全部从训练数据移除。测试只评分这些 heldout 队伍作为敌方的观测行。所有 64 队和 94,150 个有效样本都进入相应外层 OOF 预测。指标按每支 heldout 队伍单独计算后队伍等权；置信区间以队伍为重采样单位。另提供完整比赛内红蓝等权的结果作参考。

比较相同 LightGBM 预算的通用模型、追加因果敌方运动摘要的模型、以及从运动摘要构造的 K=2/3 软专家。专家聚类与归一化只在当前训练折拟合。模型输入不含学校身份或绝对 x/y；行为摘要包括敌方可见机动单位 3/9 秒速度、加速度代理、协同/推进/回撤比例、可见性和 HP 上下文。Router 仅使用运动和可见性信息。

## 结果

| 候选 | Accuracy | Macro-F1 | Brier | LogLoss |
|---|---:|---:|---:|---:|
| 通用模型 | 50.59% | 48.56% | 0.58377 | 0.96697 |
| 通用 + 可见行为摘要 | 50.95% | 48.78% | 0.58034 | 0.96148 |
| K=2 行为专家 | 50.94% | 48.75% | 0.58017 | 0.96124 |
| K=3 行为专家 | 50.96% | 48.80% | 0.58026 | 0.96137 |

行为摘要相对通用模型（64 个队伍等权）：Accuracy +0.356pp，95% CI [−0.005,+0.714]pp；Macro-F1 +0.226pp [−0.169,+0.628]pp；Brier −0.00344 [−0.00451,−0.00235]；LogLoss −0.00549 [−0.00715,−0.00383]。因此近期运动提供了可迁移到未见队伍的概率信号，但当前证据未确认硬分类增益。

风格专家相对相同行为输入的 Accuracy 差：K=2 为 −0.013pp [−0.078,+0.050]，K=3 为 +0.014pp [−0.037,+0.069]；Macro-F1 也都跨零。K=2/3 的 Brier 分别再改善 −0.000163 [−0.000244,−0.000082]、−0.000073 [−0.000107,−0.000036]，绝对量级很小；ECE 没有稳定改善。故不值得为了这点概率损失差而增加独立专家和预测器切换逻辑。

整场红蓝等权的行为摘要 Accuracy 为 50.82%，通用模型 50.45%；按 complete-game bootstrap 评估差值，逐场配对详情见 JSON 报告。所有模型的整体准确率仍约 50%，所以这不是强预测器；更稳妥用途是把概率趋势作为全局分析的一个弱参考，并与移动方向、可见率一起展示。

## 决策

1. 用队伍名分折后可以说模型测试过对未见学校队伍的迁移；不能据此给某队永久贴标签，因为队伍内部打法会随局势变化。
2. 保留因果可见行为摘要，优先作为概率质量信息。硬分类 accuracy 增益尚不显著，应保持低/中等权重并分开记分。
3. 不启用 K=2/3 风格专家；它们没有准确率收益，概率收益极小。
4. 训练顺序应从当前局势识别“此刻正在采取的行为”而非预测学校固定风格；再检验行为状态×预测器路由能否在整队留出数据上实质超过 generic+behavior。
5. 现有 chronological test 队伍与 train 无重叠，但 test 曾在项目里被反复查看，不能把它当作新盲测。后续严格验收要预先冻结模型、行为类别、损失和指标，再决定是否把历史 test 仅用于一次确认，或另收新赛季比赛。
