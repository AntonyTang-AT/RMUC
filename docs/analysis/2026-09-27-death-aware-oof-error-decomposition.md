## 解释限制

分桶结果是诊断相关性，不证明因果。低可见槽可能表示遮挡或状态缺失，也会改变可评估样本构成；剩余时间是回放时间剩余代理。若压缩 schema 对单类兵种只留一个代表，当前局面 push-score 会漏掉其余同类单位。请优先把“游戏等权准确率及区间、分桶覆盖率、类别召回”作为诊断读数。

## 可行动的误差线索

- 在当前压缩特征可复算的分数代理中，远离±1分界（距离>1.5）的blend准确率为10/30/60/120s的89.7%/79.2%/69.7%/68.9%；靠近分界（距离≤0.25）则是61.5%/54.8%/53.0%/49.5%。说明最可行动的优化方向是阈值附近的犹豫处理与未来模式切换，而不是再增加一个普遍分类器。注意这是代理分数而非精确原始战场分数。
- 临近对局尾段时整体更难：10s在剩余0–60秒的准确率71.0%，在360–420秒分段为62.7%；30s相应为62.8%和50.3%；60s为60.4%（剩余60–120秒）和46.2%；120s只有剩余120秒以上的样本。这是稀疏的对局阶段相关性，可能同时受终局战局变化和长时距可评分样本筛选影响，不能直接改成按时间切换模型。
- 当前类别分桶显示明显的持续性倾向：以当前进攻为条件时10s预测进攻召回94.5%，但真实未来防守仅3.4%会被识别；当前防守同样表现为防守召回94.8%。应专门评估预警“攻转守/守转攻”的召回与提前量；均衡类别应增加置信区间/拒判选项或作为概率输出，不能只看总准确率。
- 敌方可见类型槽分桶覆盖有限：当前压缩快照只出现4–6个有位置槽，绝大部分是6槽。它不是机器人数量，所以本轮不能据此断言“能见敌人越少模型越差”；应先从原始可观测机器人记录构建实际敌方可见数，再做同一分桶比较。

这些关联只用于定位下一项诊断或设计候选，不构成因果结论，也没有据此调整阈值或模型。
