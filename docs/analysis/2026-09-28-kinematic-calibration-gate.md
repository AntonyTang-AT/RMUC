# 运动学约束与区域先验复测

## 结论

本轮候选没有通过位置预测准入门槛，因此不替换当前生产模型，也不把该候选的全量结果写成正式成绩。评估流程在样本门禁阶段停止，避免为一个已知回归版本消耗完整评估资源。

## 修改

- `hierarchical_expert_v2_kinematic`：位置头改为速度漂移加有界残差。
- `hierarchical_expert_v3_kinematic`：对低速单位增加静止门控，收紧短时残差预算，并按 x/y 场地尺度分别限制位移。
- 增加敌方质心速度到 4×3 粗区域的推理先验，权重随时距衰减。
- 流式评估器增加 `--position-alpha`，用于扫描模型位置与持久性位置的融合比例。

## 冒烟结果

样本为每局红蓝均衡抽样，11,776 行，CUDA 推理。

| 时距 | 全局态势 | 敌方区域（模型/持久性） | 位置 MAE（模型/持久性） |
|---|---:|---:|---:|
| 10s | 0.633 | 0.618 / 0.686 | 0.076 / 0.058 |
| 30s | 0.576 | 0.546 / 0.556 | 0.147 / 0.095 |
| 60s | 0.547 | 0.523 / 0.507 | 0.194 / 0.115 |
| 120s | 0.515 | 0.486 / 0.464 | 0.232 / 0.132 |

位置融合扫描也没有超过持久性基线：`alpha=0.25` 时 10/30/60/120s 的 MAE 为 0.0587/0.0993/0.1219/0.1397，`alpha=0.10` 时为 0.0577/0.0953/0.1159/0.1326，均略高于对应基线。

## 判定

区域速度先验对 10s 有改善，但仍未超过持久性基线；长时距收益不稳定。位置头则明确回归，说明当前聚合实体目标与速度漂移之间存在标签/粒度不匹配。下一轮应拆出独立的相对位移目标和区域迁移目标，在训练中直接监督 `Δx/Δy`、到达区域和可达路径，而不是继续扩大共享位置头的解码范围。
